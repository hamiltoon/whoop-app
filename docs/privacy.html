Privacy Policy

Last updated: May 25, 2026

What This App Does

This is a personal-use application that connects to the Whoop API to retrieve your health and fitness data (recovery, sleep, workouts, cycles, and profile information).

Data Collection

This app does not collect, store, or share any personal data beyond what is needed to maintain your active session. Specifically:

  • OAuth tokens are stored in memory only and are lost when the server restarts.
  • No data is persisted to disk or transmitted to third parties.
  • No analytics, tracking, or telemetry is used.

Data From Whoop

Data retrieved from the Whoop API is displayed to you and is not stored, shared, or processed beyond what you see in the app.

Third-Party Services

This app communicates only with the Whoop API (api.prod.whoop.com). No other third-party services are used.

Contact

For questions about this privacy policy, open an issue on the GitHub repository.
